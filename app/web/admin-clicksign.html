Configuração de credenciais

O token da Clicksign é mantido somente nas variáveis de ambiente do servidor e nunca é exibido ou salvo no Git.

CLICKSIGN_ENABLED=true
CLICKSIGN_BASE_URL=https://sandbox.clicksign.com/api/v3
CLICKSIGN_API_TOKEN=seu_token
CLICKSIGN_WEBHOOK_URL=https://app.zeregistra.com.br/v1/webhooks/clicksign

Após configurar as variáveis, recrie o serviço da API. O webhook deve estar acessível publicamente para receber os eventos de assinatura.
